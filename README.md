# mandelbrot-bulbs-and-ford-circles-research

Research branch `bulb-ford-correction`: the size of the satellite bulbs of the Mandelbrot set
(and of every hyperbolic component of the quadratic family) beyond the Ford-circle law `q⁻²`.

- **Register:** [`RESEARCH_bulb-ford-correction.md`](RESEARCH_bulb-ford-correction.md) — PROVEN / VALIDATED / CONJECTURED / FALSIFIED, with the theorem
  `ρ = 1 − q²ε + q³(ι_{p/q} − ½)ε² + O(ε³)` (P2) tying the second-order bulb shape to the holomorphic index of the parabolic point.
- **Paper:** [`paper/kappa0.pdf`](paper/kappa0.pdf) (source `paper/kappa0.tex`; tables and figures regenerated by `paper/tables.py`, `paper/figures.py`) — *A parabolic-renormalization constant governing the shape of the 1/q bulbs of the Mandelbrot set*: the index formula, `κ₀ = ι(𝒫₀) − ½` (27 digits), bounded-`p` and degree-3 predictions, the kinematic `O(1/q)` correction, and the renormalization hierarchy `κ_k → κ_* = 0.011929183413 − 0.037455493752i` (levels ≤ 3 confirmed on bulbs).
- **Code:** `bulbford/` (dynamics with a numba kernel, parabolic index and normal form in ball arithmetic, Taylor data of the multiplier, horn maps and Fatou coordinates, renormalization predictions, extrapolation), `tests/` (pytest), `scripts/` (sweeps and experiments), `data/` (results), `legacy/` (the original instruments, unmodified).
